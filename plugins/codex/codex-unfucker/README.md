# Codex Unfucker

Diagnose and fix Codex sandbox failures, especially Windows command-launch failures. Invoke `$unfuck-sandbox` in Codex. The skill needs access to the affected Codex installation and its configuration; Windows-specific checks require Windows and, where applicable, the Codex CLI. Some repairs require restarting Codex or administrator approval. Installed-host discovery and activation must be checked separately.
