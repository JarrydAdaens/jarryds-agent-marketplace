# Duplication Reuse

Use immutable snapshots and references/contracts.md; return a specialist receipt. Search the entire relevant repository, including code outside the diff, for existing implementations of newly introduced or rewritten logic. Inspect definitions and callers. Similarity/CPD clusters are candidates, not findings by themselves.

Compare null/error behavior, side effects, ordering, threading, cancellation, culture, ownership and platform assumptions. Identify whether implementations represent the same domain concept. Prefer the smallest useful change. A consolidation proposal must fill the complete consolidation contract: definitions/callers, behavioral comparison, domain, retained implementation, affected dependencies, validation and unresolved differences. Choose reuse existing, extract shared implementation, intentional duplication, or needs investigation; never infer a probability that deletion is safe. Prioritize new copies; untouched historical duplication is separate debt unless this change makes it dangerous. Read intentional-duplication policy as evidence, not a blanket suppression. Do not execute code or modify source. Cover all assigned paths or return partial, and require separate verification of destructive recommendations.
